# 项目记忆：美语听读发音评分系统 (English_Reading)

## 定位
面向中文用户的标准美式发音英语学习 Web 应用：听读 → 跟读 → 复读对比 → 发音评分。飞哥自用，部署在公网 IP。

## 硬约束 / 约定（务必遵守）
- **零依赖**：`server/` 只用 Node 内置模块；前端原生 ESM，无构建。`package.json` 已 `"type":"module"`，`dependencies` 为空。改代码不要引入新依赖。
- **默认零配置可用**：`TTS_PROVIDER=edge`（免费微软神经真人语音，无需 Key，男/女声自然音色）+ `ASSESS_PROVIDER=offline`（自实现 DSP 离线声学引擎）。断网时前端自动回退浏览器语音；云端 azure/tencent/openai 是可插拔适配器，缺密钥时**自动回退**并前端提示，功能不中断。
- **Edge 真人语音**：`server/tts/edge.js` + 零依赖手写 WS 客户端 `server/lib/ws.js`。**坑**：端点要求 Client Hints 头 + Chromium 版本 ≥138（否则握手 403），GEC 用 BigInt 精确算。音色在 `SERVER_VOICES.edge`（10 个 en-US）。支持长文本（synthesize 上限 3000 字符）。
- **自定义素材朗读方式**：`makeCustomGroup(title,text,mode)`，mode ∈ auto(自动分句)/paragraph(按空行分段)/whole(整篇)；`splitParagraphs` 按空行拆。录音上限随文本长度自适应（≤5min）。
- **默认端口 7000**（曾定 8080→7070，7070 被旧进程占用遂定 7000）。
- **录音格式**：AudioWorklet 采 PCM → 重采样 16kHz → 编码单声道 16bit WAV（兼容离线 DSP 与云端评测，不依赖 ffmpeg）。
- **数据**：`data/users/<uid>.json` 每用户一文件（内存缓存 + 串行写）。`DATA_DIR` 可改。
- **HTTPS 必须 / 局域网自签名**：浏览器只在 https/localhost 允许麦克风。公网部署需反代 + TLS；局域网测试已在 `certs/` 内置自签名证书（CN=192.168.0.8，SAN 含 127.0.0.1/192.168.0.8），服务检测到 `cert.pem+key.pem` 即自动启用 HTTPS。可用 `SSL_ENABLED=false` 关闭。
- **移动端 H5**：`≤900px` 显示汉堡菜单抽屉（左侧滑出），桌面端保持顶部 tabs。
- **PWA（2026-09-29 一期）**：`public/manifest.webmanifest` + `sw.js` + `offline.html` + `js/pwa.js`。缓存策略刻意保守：HTML/JS/CSS network-first（防旧代码坑复发），materials.json stale-while-revalidate（离线可练），`/api/*` 不缓存。SW 的 `CACHE` 常量带版本号，改 SW 必须升版本。图标零依赖生成 `scripts/gen_icons.mjs`（node:zlib 手写 PNG + SDF，禁引 sharp/canvas）。**可安装硬前提 = 受信任 HTTPS**；自签名下 Chrome 不弹安装入口，根治靠域名 + Let's Encrypt。

## 关键文件
- `server/server.js`：路由表。`server/config.js`：读 .env + `capabilities()`（不含密钥）。
- `server/assess/offline.js` + `server/lib/dsp.js`：离线评分核心（FFT/MFCC/VAD/音节核/DTW）。
- `server/tts/index.js`：云端 TTS 三实现 + 磁盘缓存 + `SERVER_VOICES`。
- `public/index.html` + `public/js/*`：四视图 SPA（main.js 为入口）。
- `public/data/materials.json`：内置分级素材，10 个 level / **250 组 / 1402 条**（version 7）。结构 `{version,updatedAt,levels:[{id,name,desc,groups:[{id,type,title,desc,items:[{text,ipa?,zh,focus?}]}]}]}`。level 顺序：beginner/intermediate/advanced/drills（发音专项+工程模具外贸）、**primary/junior/senior（各 4 版本 × 5 主题 × 3 类 = 60 组 / 320 条）**、**cet/ielts/toefl（各 5 话题 × 3 类 = 15 组 / 80 条）**。每主题 12 词（带美音 IPA）+ 3 句 + 1 段。重构脚本 `scripts/build_curriculum_phase1.mjs`（小学）、`scripts/build_curriculum_phase2.mjs`（初中/高中/考试）。**版权安全**：内容为按版本/话题原创生成，未照搬原版课文。段落组 id 以 `-p` 结尾，每条 `{text,zh}` 无 ipa。group title 固定格式 `"版本名 · 主题名 · 类型名"`，practice.js 靠它做 `<optgroup>` 分组与"版本名 · 类型"标签。
