# 让 PC 与手机信任证书，并把应用「安装成 APP」

背景：你的服务器是**腾讯云轻量 + 公网 IP、没有域名**。Let's Encrypt 只给域名签证书，
所以这里走**自建根 CA** 路线：服务器用自建 CA 签发证书，你的每台设备信任这根 CA（**一次性，永久有效**）。
完成后 `https://<公网IP>:7000` 是真正的绿锁站点 —— 麦克风可用，**APP 也能安装**。

> 前提：已在服务器跑过 `IP=<公网IP> bash scripts/deploy/gen_tls.sh`，得到 `certs/ca.pem`。

---

## 0. 先把 root CA 弄到设备上

在服务器上查看根证书内容，复制粘贴到设备，或用 scp：

```bash
cat certs/ca.pem          # 复制这段 -----BEGIN CERTIFICATE----- ... -----END CERTIFICATE-----

# 或者传到本机后再用微信/QQ/邮件发到手机
scp root@<公网IP>:~/English_Reading/certs/ca.pem ./ca.pem
```

> ⚠️ **只分发 `ca.pem`（根证书公钥）。`ca.key` 是私钥，永远不要离开服务器。**

手机上推荐把 `ca.pem` 发到微信文件传输助手 / 邮件，用浏览器打开下载即可。

---

## 1. Windows（电脑）

```powershell
# 以管理员 PowerShell 执行（普通用户也可以，会装到当前用户，效果一样）
certutil -addstore -user Root .\ca.pem
```

或图形界面：双击 `ca.pem` →「安装证书」→ 选「当前用户」→「将所有证书放入下列存储」→ 浏览 → 选**受信任的根证书颁发机构** → 完成。

**验证**：Chrome 打开 `https://<公网IP>:7000`，地址栏应是🔒绿锁、无警告。

---

## 2. Android（手机）

1. 把 `ca.pem` 传到手机（微信/邮件均可，路径无所谓）。
2. **设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书**（不同 ROM 措辞略有差异，搜「安装证书」即可）。
   - 小米 / 华为 / OPPO：设置里搜「**证书**」或「**凭据**」。
   - 注意**不要**误选成「WLAN 证书」或「应用证书」，必须是 **CA 证书**。
3. 选择 `ca.pem`，确认后系统会提示已安装。
4. Chrome 打开 `https://<公网IP>:7000`，应为绿锁。

> Android 7+ 会提示「网络可能被监控」，这是安装用户 CA 的正常提示，自用无损。

---

## 3. iPhone / iPad

1. 把 `ca.pem` 传到手机，用 **Safari** 打开该文件（会弹出「下载描述文件」）。
2. **设置 → 通用 → VPN 与设备管理** → 找到刚下载的描述文件 →「安装」。
3. **关键一步**：**设置 → 通用 → 关于本机 → 证书信任设置** → 打开对该根证书的「完全信任」。
4. Safari 打开 `https://<公网IP>:7000`，应无证书警告。

> iOS 少了第 3 步就会始终提示不受信任 —— 这是最常见漏做的一步。

---

## 4. 安装成 APP

证书信任完成后，访问 `https://<公网IP>:7000`：

| 平台 | 操作 |
|------|------|
| **Android Chrome / Edge** | 页面顶栏出现 📲 按钮 → 点它 →「安装」；或在浏览器菜单里「安装应用 / 添加到主屏幕」 |
| **iPhone Safari** | 点底部「分享」↑ →「添加到主屏幕」→ 右上角「添加」 |
| **Windows Chrome / Edge** | 顶栏 📲 按钮；或地址栏右侧的「安装」图标 →「安装」 |

安装后：桌面出现 🎧 图标，点开是**独立全屏窗口，没有地址栏**，跟原生 APP 一样。
离线时还能打开继续浏览已缓存的素材（评分/录音需联网）。

## 5. 常见问题

**Q：一年后会不会失效？**
会。叶子证书故意只签 **365 天**（Apple 规定 iOS 只接受 ≤398 天的证书）。到期前在服务器重跑一次即可：

```bash
IP=<公网IP> bash scripts/deploy/gen_tls.sh
docker restart english-reading
```

因为根 CA 是 10 年有效的，**设备不用再重新安装任何东西**，重签后自动恢复绿锁。
（建议记个日历提醒：每年到期前一周。）

**Q：换了公网 IP？**
用新 IP 重跑上面的命令重签即可，同样不用动设备。

**Q：为什么不干脆买个域名 + Let's Encrypt？**
完全可以，而且更省事（不用给每台设备装证书）。但要留意：
- Let's Encrypt 签发通常需要 80 端口做 HTTP-01 验证，国内云服务器绑域名会牵扯**备案**；
- 本方案的好处是**零成本、当场可用、不受备案限制**（走 IP + 非标准端口 7000）。
等你想上域名了，只要在 Nginx 反代后面换张 Let's Encrypt 证书即可，应用本身不用改。

**Q：务必确认的腾讯云安全组**
轻量云控制台 → 防火墙 → 添加规则：**TCP 7000 放行**（这是「打不开」最常见的原因）。
